⚙️ Run it on your computer (free)

This page is the app. The AI runs on your computer through ComfyUI, so it's free and private.

  1. Use Google Chrome. Safari blocks web pages from talking to your computer. If Chrome asks to allow access to your local network, click Allow.
  2. Install ComfyUI and download the models into your ComfyUI/models/ folders (about 48 GB total):
    StatusModelPut it inSize

    Video needs an NVIDIA GPU with 16 GB of VRAM or more. On a Mac the image steps work, but the 22B video model is too heavy; use Comfy Cloud at the bottom for video.

  3. Start ComfyUI and allow this site:
    Windows (portable)
    Mac / Linux
    ComfyUI DesktopSettings → Server-Config → Enable CORS header:
  4. Refresh this page. The dot at the top right turns green and the model list shows ✓.

Comfy Cloud API optional

Runs locally with open weights by default. Add your Comfy API key to run the same workflows on Comfy Cloud GPUs and plug in more models.

Get a key at platform.comfy.org/profile/api-keys. The key is stored only in this browser and sent only to Comfy Cloud.
